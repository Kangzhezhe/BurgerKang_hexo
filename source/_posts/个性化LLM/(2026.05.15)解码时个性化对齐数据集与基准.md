# 个性化文本生成实验设置 (Experimental Setup)

## 一、 数据集选择 (Datasets)

本实验严格聚焦于纯自然语言个性化生成任务，排除了任何代码生成或逻辑编译相关任务。为全面验证系统在不同文本长度、风格方差以及数据稀疏度下的个性化对齐能力，构建了以下包含四个梯度的核心数据集矩阵：

### 1. LaMP-4 (个性化新闻标题/摘要生成)
* **定位**：学术基准与客观事实保真度测试 (Academic Baseline & Content Fidelity)。
* **数据特征**：文本客观严谨，包含明确的新闻事件与实体。
* **核心考察点**：模型在隐式提取用户标题命名偏好时，是否会发生事实幻觉。这是确立架构有效性的第一道核心测试标准。

### 2. Yelp (本地商家点评)
* **定位**：极端情绪与微观习惯对齐 (Extreme Emotion & Micro-style Alignment)。
* **数据特征**：中短篇幅，方差极大，包含大量口语化表达、特殊标点和主观情绪词汇。
* **核心考察点**：打破基座模型预训练的通用表达，测试系统提取和还原用户高频俚语及情绪极性的能力。

### 3. Goodreads (书评数据)
* **定位**：长文本复杂文体维稳 (Long-context Fidelity & Complex Syntax)。
* **数据特征**：长篇幅文本，词汇丰富度高，包含大量复杂句式与深层逻辑思辨。
* **核心考察点**：检验系统在生成超长文本时，是否能有效缓解“中间迷失”与“词汇降级”，并在长上下文中保持事实与复杂风格的解耦。

### 4. Amazon (亚马逊商品评论)
* **定位**：真实世界稀疏数据与跨域泛化 (Data Sparsity & Cross-domain Generalization)。
* **数据特征**：绝大多数用户历史交互极少（K ≤ 3），且评论跨越极其庞杂的商品品类。
* **核心考察点**：在离线偏好记忆数据库极度匮乏的冷启动场景下，系统的鲁棒性与特征泛化提取能力。

## 二、 基线对比方案 (Baseline Methods)

为充分证明本研究架构的优越性，对比实验覆盖了当前纯文本个性化生成的四大主流技术路线。所有对比均在**无需对基座模型进行全参数微调（Training-free）**的前提下进行。

### 1. 基础检索增强流派 (Vanilla RAG)
* **代表方法**：BM25 + LLM (Zero-shot) / Contriever + LLM
* **技术逻辑**：直接利用传统或稠密检索算法从用户历史中召回 Top-K 篇文本，与当前 Query 简单拼接后送入模型生成。
* **对比目的**：作为实验的下界（Lower Bound），证明生硬的 Prompt 拼接无法实现高维的语义融合。

### 2. 离线属性索引流派 (Advanced RAG)
* **代表方法**：EXACT
* **技术逻辑**：通过离线属性提取构建高密度的个性化标签，在线推理时结合语义检索模型召回特定风格约束进行生成。
* **对比目的**：证明本架构在隐式特征捕捉上，比单纯依赖显式标签字典更加丰富且不易丢失微观语气。

### 3. 底层概率干预流派 (Decoding-Time Intervention)
* **代表方法**：Drift / CoSteer
* **技术逻辑**：利用小型语言模型（sLLM）在解码期计算个性化的 Logit 偏移量，并在推理时将其直接融合到基座模型的生成概率分布中。
* **对比目的**：对比底层 Logit 操控与本架构顶层语义机制的优劣，证明纯文本层面的并发引导依然能达到极高的对齐精度，且完美兼容黑盒 API。

### 4. 测试时迭代反馈流派 (Test-Time Optimization)
* **代表方法**：PerFine
* **技术逻辑**：基于“检索-批评-重写”的线性单线迭代。利用本地 Critic 模型并行输出关于语气、词汇、句式、主题等结构化维度的文本反馈，大模型据此进行淘汰赛式的修改。
* **对比目的**：作为最直接的竞品，证明本架构的并发式生成与注意力全局融合机制，能有效克服 PerFine 线性迭代带来的原始事实遗忘问题。

## 三、 评估指标 (Evaluation Metrics)

实验统计以下两类独立指标，以量化个性化质量与事实保真度的平衡：

1. **事实保真度 (Content Preservation)**：采用 ROUGE-1/2/L，严格监控在复杂风格迁移下，生成文本与参考文本之间的关键事实召回率（重点应用于 LaMP-4 和 Goodreads）。
2. **个性化对齐度 (Personalization Alignment)**：利用大模型作为裁判（LLM-as-a-Judge, 基于 GEval 协议），针对生成文本的语气、句式和独特词汇命中率进行盲测打分（重点应用于 Yelp 和 Amazon）。

## 四、 实验对比概览矩阵

| 对比流派 | 代表方法 | 核心技术特征 | 预期局限性分析 |
| :--- | :--- | :--- | :--- |
| **基础检索基线** | Vanilla RAG | 文本生硬拼接 | 易产生机械的复制粘贴，风格融合度极差。 |
| **属性检索优化** | EXACT | 离线索引 + 显式标签 | 标签过度压缩导致微观情绪与口语习惯丢失。 |
| **底层概率引导** | Drift | sLLM Logit 偏移 | 强依赖白盒模型，无法泛化至强大的闭源 API。 |
| **测试时文本重写** | PerFine | Critic 多维反馈 + 单线修改 | 多轮线性重写极易丢失长文本的客观事实骨架。 |
| **本研究架构** | **(Ours)** | **并行计算引导 + 结构化多维融合** | **同时实现风格极致对齐与客观事实防遗忘。** |
