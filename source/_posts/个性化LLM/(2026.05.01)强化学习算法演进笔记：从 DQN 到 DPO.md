# 强化学习算法深层演进：从离散建模到解析对齐

这是一份关于强化学习（RL）核心算法演进的深度笔记。本笔记聚焦于每种算法的核心痛点、数学突破以及它们如何一步步演化为大模型对齐（Alignment）的主流方案。

---

## 1. DQN (Deep Q-Network)：价值学习的深度化
**核心使命**：解决“泛化（Generalization）”问题，证明深度神经网络可以作为强化学习的函数逼近器。

### 1.1 数学核心：贝尔曼最优方程
DQN 试图通过最小化 **时序差分 (TD) 误差** 的平方来逼近最优价值函数：
$$L(\theta) = \mathbb{E}_{(s, a, r, s') \sim \mathcal{D}} \left[ \left( y^{DQN} - Q(s, a; \theta) \right)^2 \right]$$

其中 **目标值 (Target)** 定义为：
$$y^{DQN} = r + \gamma \max_{a'} Q(s', a'; \theta^-)$$

### 1.3 核心技术突破
* **经验回放 (Experience Replay)**：存储轨迹数据 $(s, a, r, s')$，采样时打破时间相关性，满足 IID 假设。
* **目标网络 (Target Network)**：引入延迟更新的参数 $\theta^-$，缓解目标值不断变动导致的“追逐移动目标”问题。
* **局限**：无法直接处理连续动作空间；由于 $\max$ 操作，容易产生过度估计（Overestimation）。



---

## 2. Actor-Critic (AC)：实时性与连续空间的平衡
**核心使命**：解决“方差与偏差”的博弈，实现单步更新，并适配连续动作空间。

### 2.1 架构设计
* **Actor (策略网络 $\pi_\theta$)**：学习动作分布，负责“做动作”。
* **Critic (价值网络 $V_\phi$)**：学习状态价值，负责“打分”。

### 2.2 核心公式：基于 TD 误差的指导
Actor 的更新由 Critic 提供的 **TD 误差 ($\delta$)** 指导：
$$\delta = r + \gamma V_\phi(s') - V_\phi(s)$$

* **Actor 更新**：$\nabla_\theta J(\theta) = \mathbb{E} [ \nabla_\theta \log \pi_\theta(a|s) \cdot \delta ]$
* **公式内涵**：$\delta$ 代表了“惊喜度”。若 $\delta > 0$，现实好于预期，强化该动作概率。AC 相比于 REINFORCE 显著降低了方差。



---

## 3. TRPO (Trust Region Policy Optimization)：置信域的数学护栏
**核心使命**：解决“更新稳定性”的理论边界，确保步子迈得太大不会导致模型崩坏。

### 3.1 核心思想：信息空间约束
TRPO 不限制参数变化绝对值，而是限制**策略分布的变化（KL 散度）**。

### 3.2 数学硬核：二阶近似
在满足 KL 约束的前提下最大化代理目标：
$$\max_\theta \mathbb{E}_{s, a \sim \pi_{old}} \left[ \frac{\pi_\theta(a|s)}{\pi_{old}(a|s)} A^{\pi_{old}}(s, a) \right]$$
$$\text{s.t. } \mathbb{E}_s [ D_{KL}(\pi_{old}(\cdot|s) \parallel \pi_\theta(\cdot|s)) ] \leq \delta$$

* **数学方案**：对 KL 约束做二阶泰勒展开，引入 **费雪信息矩阵 (Fisher Information Matrix)**。
* **意义**：证明了“单调提升定理”，理论上保证新策略不差于旧策略。但计算海森矩阵（Hessian）的逆成本极高。

---

## 4. PPO (Proximal Policy Optimization)：工程落地的终极形态
**核心使命**：将 TRPO 的二阶数学约束简化为一阶的工程截断，平衡稳定性与计算效率。

### 4.1 核心公式：截断式代理目标 (PPO-Clip)
$$L^{CLIP}(\theta) = \mathbb{E} [ \min( r_t(\theta) \hat{A}_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon) \hat{A}_t ) ]$$

* **$r_t(\theta)$**：新旧策略概率比 $\frac{\pi_\theta}{\pi_{old}}$。
* **截断逻辑**：当动作较好（$A>0$）且概率增加过快（$ratio > 1.2$）时，强行切断奖励增长，防止过拟合当前数据。

### 4.2 为什么它是大模型主流？
PPO 只需要一阶梯度，易于在超大规模参数下并行，且鲁棒性极强。它是 RLHF（人类反馈强化学习）的核心优化器。



---

## 5. DPO (Direct Preference Optimization)：范式转移的解析解
**核心使命**：解决“在大模型上甩掉 RL 繁琐流程”的问题。

### 5.1 数学跃迁：从奖励到概率
DPO 发现最优策略与其奖励函数之间存在闭式解映射。通过代入 **Bradley-Terry 偏好模型**，可以直接消去奖励函数 $r$。

### 5.2 核心 Loss 函数
$$\mathcal{L}_{DPO} = - \mathbb{E} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)} \right) \right]$$

* **关键洞察**：模型只需要观察：在同一个 Prompt 下，好结果（$y_w$）相对于参考模型的概率提升，是否比坏结果（$y_l$）提升得更多。
* **优势**：无需奖励模型、无需在线采样、显存占用低、训练极其稳定。

---

## 总结：算法演进全景图

| 阶段 | 代表算法 | 核心突破 | 解决的问题 |
| :--- | :--- | :--- | :--- |
| **初期** | **DQN** | 贝尔曼方程 + 神经网络 | 证明了深度学习能做 RL |
| **进阶** | **Actor-Critic** | TD 误差 + 双网络 | 解决了单步更新与连续动作空间 |
| **稳定** | **TRPO** | 置信域 + 二阶导数 | 确立了更新稳定性的数学边界 |
| **巅峰** | **PPO** | 代理目标 + 一阶截断 | 实现了稳定性在工业界的工程落地 |
| **革新** | **DPO** | 变分反解 + 解析对齐 | 甩掉了 RL 繁琐流程，成为 LLM 对齐首选 |


# 强化学习与 DPO (Direct Preference Optimization) 深度学习笔记

## 1. 基础：策略梯度 (Policy Gradient)
强化学习的本质是让智能体在环境中通过试错最大化奖励。

### 1.1 目标函数
在 LLM 对齐中，策略 $\pi_\theta$ 的目标是最大化期望累积奖励：
$$J(\theta) = \mathbb{E}_{y \sim \pi_\theta} [R(x, y)]$$

### 1.2 策略梯度更新
通过 **Log-Derivative Trick**，我们将无法直接求导的奖励函数转换为可优化的梯度公式：
$$\nabla_\theta J(\theta) \approx \mathbb{E}_{y \sim \pi_\theta} [ \nabla_\theta \log \pi_\theta(y|x) \cdot R(x, y) ]$$
- **物理意义**：若 $R(x, y)$ 为正且较大，则增加该样本生成的概率；反之降低。

---

## 2. 约束引入：KL 散度 (Kullback-Leibler Divergence)
为了防止模型在优化过程中出现“奖励破解（Reward Hacking）”或坍缩，需要引入 **KL 散度** 作为约束。

### 2.1 数学定义
$$D_{KL}(P \parallel Q) = \sum_{x} P(x) \log \frac{P(x)}{Q(x)}$$
- **Reverse KL ($D_{KL}(\pi_\theta \parallel \pi_{ref})$)**：在 DPO 中使用此形式，因为它允许期望算子统一为 $\mathbb{E}_{y \sim \pi_\theta}$，便于数学推导。

### 2.2 最终优化目标
$$\max_{\pi} \mathbb{E}_{y \sim \pi} [r(x, y)] - \beta D_{KL}(\pi(y|x) \parallel \pi_{ref}(y|x))$$
- $\beta$：调节因子，控制模型偏离原始分布的程度。

---

## 3. 数学桥梁：变分法与最优解
通过**变分法 (Calculus of Variations)** 对上述目标函数求极值，可以推导出最优策略 $\pi^*$ 的解析形式。

### 3.1 最优策略闭式解
$$\pi^*(y|x) = \frac{1}{Z(x)} \pi_{ref}(y|x) \exp \left( \frac{1}{\beta} r(x, y) \right)$$
其中 $Z(x)$ 是**归一化常数（配分函数）**。

### 3.2 奖励函数的反解
将上式取对数并移项，可以得到用概率表示的奖励函数：
$$r(x, y) = \beta \log \frac{\pi^*(y|x)}{\pi_{ref}(y|x)} + \beta \log Z(x)$$
**关键洞察**：奖励分数的本质，其实就是当前模型相对于参考模型的对数概率提升。

---

## 4. 偏好建模：Bradley-Terry (BT) 模型
DPO 利用 BT 模型将人类的二选一（Pairwise Comparison）偏好数据进行概率化。

### 4.1 胜率公式
对于偏好对 $(y_w, y_l)$，人类选择 $y_w$ 的概率建模为：
$$P(y_w \succ y_l | x) = \sigma(r(x, y_w) - r(x, y_l))$$
其中 $\sigma$ 是 Sigmoid 函数：$\sigma(x) = \frac{1}{1+e^{-x}}$。

---

## 5. DPO 的核心推导与 Loss
DPO 的天才之处在于将 **Step 3.2 的奖励公式** 代入 **Step 4.1 的胜率公式**。

### 5.1 消去归一化常数 $Z(x)$
在计算奖励差值 $r(x, y_w) - r(x, y_l)$ 时：
$$( \beta \log \frac{\pi_\theta(y_w)}{\pi_{ref}(y_w)} + \beta \log Z(x) ) - ( \beta \log \frac{\pi_\theta(y_l)}{\pi_{ref}(y_l)} + \beta \log Z(x) )$$
$\beta \log Z(x)$ 被完全抵消，从而规避了 LLM 中难以计算的全集概率求和问题。

### 5.2 DPO 损失函数 (Final Loss)
$$\mathcal{L}_{DPO}(\pi_\theta; \pi_{ref}) = - \mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)} \right) \right]$$

---

## 6. 发展脉络总结：PPO vs. DPO

| 阶段 | 方法 | 特点 | 局限 |
| :--- | :--- | :--- | :--- |
| **RL 早期** | 直接策略梯度 | 依赖精确的奖励函数定义 | 语言任务中难以定义 Reward |
| **标准 RLHF** | **PPO** | 在线学习，通过 Reward Model 实时反馈 | 流程复杂（4个模型），显存压力大，训练极不稳定 |
| **现代对齐** | **DPO** | 离线优化，将 RL 转化为二分类任务 | 依赖偏好数据质量，容易对噪声过拟合 |

## 7. 结论
DPO 的简单性就是它的力量。它证明了通过将对齐任务重新定义为分类问题，可以规避强化学习中的不稳定性、高方差和巨大的计算开销，同时在最终效果上实现反超。  
DPO 证明了“语言模型暗地里就是一个奖励模型”，我们只需要直接提取这个能力，而不需要去模拟一个复杂的强化学习环境。
